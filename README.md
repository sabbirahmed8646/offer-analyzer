# Offer Analyzer — ডেপ্লয়মেন্ট গাইড (ধাপে ধাপে)

## ধাপ ১: Anthropic API Key নিন
1. https://console.anthropic.com এ যান, একাউন্ট খুলুন
2. বাম দিকে "API Keys" এ ক্লিক করুন → "Create Key"
3. Key-টা কপি করে রাখুন (এটা আর দেখা যাবে না, তাই এখনই সেভ করুন)
4. "Billing" থেকে সামান্য কিছু ক্রেডিট যোগ করুন (শুরুতে $5-10 যথেষ্ট)

## ধাপ ২: প্রজেক্ট GitHub-এ আপলোড করুন
1. https://github.com এ লগইন করুন
2. উপরে ডানদিকে "+" → "New repository"
3. নাম দিন: `offer-analyzer` → Create repository
4. এই পুরো ফোল্ডারটা (যেটা আমি দিয়েছি) আপলোড করুন:
   - GitHub এর "uploading an existing file" লিংকে ক্লিক করে ফাইলগুলো ড্র্যাগ করে দিন
   - অথবা GitHub Desktop অ্যাপ (https://desktop.github.com) ইনস্টল করে সহজে আপলোড করতে পারেন

## ধাপ ৩: Vercel-এ ডেপ্লয় করুন
1. https://vercel.com এ যান, GitHub দিয়ে লগইন করুন
2. "Add New" → "Project" ক্লিক করুন
3. আপনার `offer-analyzer` রিপোজিটরি সিলেক্ট করে "Import" করুন
4. "Environment Variables" সেকশনে যোগ করুন:
   - Name: `ANTHROPIC_API_KEY`
   - Value: (ধাপ ১ থেকে কপি করা key)
5. "Deploy" বাটনে ক্লিক করুন
6. ১-২ মিনিট পর একটা লাইভ লিংক পাবেন (যেমন: `offer-analyzer.vercel.app`)

## ধাপ ৪: টেস্ট করুন
1. লাইভ লিংকে যান
2. একটা অফারের নাম বা লিংক লিখে "অ্যানালাইজ করুন" চাপুন
3. কয়েক সেকেন্ডে AI রিপোর্ট চলে আসবে

---

## লোকাল কম্পিউটারে টেস্ট করতে চাইলে (ঐচ্ছিক)
যদি নিজের কম্পিউটারে আগে টেস্ট করতে চান:
```
npm install
```
তারপর `.env.example` ফাইলের নাম পরিবর্তন করে `.env.local` করুন এবং সেখানে আপনার API key বসান। এরপর:
```
npm run dev
```
ব্রাউজারে `http://localhost:3000` খুলুন।
